🌈 Kidzo App

Kidzo is a fun and interactive kids learning application designed to make early education enjoyable.
The app introduces children to colors, shapes, stories, and rhymes in a playful and engaging way.
It also comes with voice narration and sing-along features so that children can listen, repeat, and learn naturally.

Unlike traditional apps that focus on just one language, Kidzo supports multiple Indian languages—helping children learn in their mother tongue while also exploring English.

👉 Live Demo: https://kidzo-production.up.railway.app/
🧒 Why Kidzo?

Kids learn best through play, visuals, and sound.

Many apps only support English, but Kidzo allows learning in Telugu, Kannada, Hindi, and English.

It creates an inclusive environment where kids from different backgrounds can enjoy learning.

With voice narration, even pre-readers (kids who cannot yet read) can learn by listening.

✨ Key Features

🎨 Colors & Shapes – Simple and vibrant visuals to teach kids basics.

📖 Stories & Rhymes – Interactive and fun content that children love.

🎤 Voice Narration & Sing-Along – Audio guidance makes learning easy and fun.

🌍 Multi-Language Support – Kids can switch between:

Telugu

Kannada

Hindi

English

🎧 Child-Friendly Design – Safe, distraction-free, and easy to use.

🛠️ Tech Stack

Backend: Python (Flask)

Frontend: HTML, CSS, JavaScript

Database: SQLite (kids_learning_app.db)

Deployment: (Replit / Render / etc.)

🚀 Getting Started (For Developers)
1️⃣ Clone the repository
git clone https://github.com/your-username/kidzo-app.git
cd kidzo-app

2️⃣ Install dependencies
pip install -r requirements.txt

3️⃣ Run the app locally
python app.py


Now visit http://localhost:5000
 in your browser to explore the app.

📂 Project Structure
├── app.py                # Main Flask app
├── templates/            # HTML templates (UI)
├── static/js/            # JavaScript files (interactivity)
├── data/                 # Learning data (stories, rhymes, etc.)
├── kids_learning_app.db  # SQLite database
├── requirements.txt      # Python dependencies
└── pyproject.toml        # Project config
